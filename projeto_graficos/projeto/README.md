# Visualização de Dados

Um script Python para cada gráfico, cada um lendo seu respectivo CSV.

| Script | Dados | Gráfico |
|---|---|---|
| `01_grafico_barras.py` | `dados_barras.csv` | Barras agrupadas |
| `02_grafico_boxplot.py` | `dados_boxplot.csv` | Boxplot |
| `03_grafico_dispersao.py` | `dados_dispersao.csv` | Dispersão |
| `04_grafico_distribuicao.py` | `dados_distribuicao.csv` | Histograma + densidade |
| `05_grafico_frequencia.py` | `dados_frequencia.csv` | Frequência (contagem) |
| `06_grafico_heatmap.py` | `dados_heatmap.csv` | Heatmap |
| `07_grafico_linhas.py` | `dados_linhas.csv` | Linhas (série temporal) |
| `08_grafico_pizza.py` | `dados_pizza.csv` | Pizza |
| `09_grafico_regressao.py` | `dados_regressao.csv` | Regressão linear |

## Como executar

```bash
pip install -r requirements.txt
python 01_grafico_barras.py
```

As imagens são salvas na pasta `graficos/`.
